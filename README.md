# Cafe Menu

A simple cafe menu webpage built with HTML and CSS as part of the freeCodeCamp Responsive Web Design curriculum.

## Overview

This project features a cafe menu displaying different coffee flavors and desserts, alongside their prices. It was created to practise styling web pages using CSS.

## Features

- Displays a coffee menu with prices.
- Displays a dessert menu with prices.
- Uses a background image.
- Includes a cafe name, establishment year, and footer.
- Features interactive link hover and active states.

## Technologies Used

- HTML5
- CSS3

## What I Learned

- Applying CSS styles to HTML elements.
- Using classes and selectors to target specific elements.
- Working with margins, padding, and widths.
- Styling text, backgrounds, and images.
- Using pseudo-classes to style links.
